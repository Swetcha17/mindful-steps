# Mindful Steps

A simple and engaging project designed to **turn physical steps into mindful moments** - encouraging users to be present, track movement, and reflect on everyday walking as a practice of mindfulness and awareness.

*This repository contains the source code and assets for the Mindful Steps project.*

## Overview

Mindful Steps is intended to help users:

- Track steps or walking activity
- Prompt users to pause and observe their surroundings
- Encourage reflection, awareness, and presence
